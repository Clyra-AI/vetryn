# OpenRouter TypeScript example

This directory will hold the first end-to-end fixture repository for the supported V1 path:

- TypeScript on Node.js
- the `openai` SDK configured for OpenRouter
- a direct, statically pinned model literal
- JSON or tool-call output
- checked-in, human-reviewed eval cases

The example will be added with the scanner implementation. Until then, the repository is intentionally
explicit that Vetryn is pre-alpha and not ready for production migrations.
