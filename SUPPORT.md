# Support

Vetryn is community-supported and pre-alpha.

- Use [GitHub Discussions](https://github.com/Clyra-AI/vetryn/discussions) for questions, ideas, and design
  exploration.
- Use [GitHub Issues](https://github.com/Clyra-AI/vetryn/issues) for reproducible bugs and accepted feature
  work.
- Use [private vulnerability reporting](SECURITY.md) for security concerns.

Public community support has no response-time guarantee. Please do not share API keys, customer prompts,
production traces, or other confidential data in any public channel.
